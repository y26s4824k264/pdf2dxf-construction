# 模板来源与验证边界

内置中文字库保留 101 个模板、63 个字符。93 个模板要求相同人工审核标签和完整字形在至少两个源 PDF 中精确一致；另 8 个仅用于完整比例字符串，并要求独立工程数字模板佐证。原图和人工审核截图属于内部验证资料，不包含在独立发布目录中。

每条模板的 `label_evidence` 保留来源 SHA256、页码、标签和审核方法；这提供来源关联，不等于独立的许可证明。公开目录不含完整原图，所以使用者能复核数据内部一致性，但不能仅靠此目录重新执行原始人工审图。

中文字典完整模板集合 SHA256：`de15c488e3a7b82bb0e2f6275107046718b7b28c13975928bbe91dea78c8e2ec`。rc15 仅改变字典顶部的审核文档链接，不改变模板行、几何指纹和标签证据。

工程字形文件记录了 SHX 来源。维护者于 2026-09-07 授权公开随包衍生模板和两份回归 fixture，记录见 [SOURCE_ORIGIN.json](../SOURCE_ORIGIN.json)。这是维护者声明，并非独立法律核验；不扩展为对源 SHX、外部字体程序或原始图纸的授权，见 [第三方说明](../THIRD_PARTY_NOTICES.md)。

外部字库由用户提供的 OpenType 字体建立，运行时只读取持久化 `.p2dfont` 与 DXF。字符覆盖受字体实际 cmap 和可提取轮廓限制；没有单个字库能保证识别任意未知字体。外部字体须以三个不同的相邻汉字精确命中或三个已审锚点锁定，冲突和孤立候选继续保留几何。
